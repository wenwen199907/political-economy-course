# 政治经济学导论网页发布版

这是一个零构建、零外部依赖的静态网站。

- `index.html`：课程入口
- `lecture01.html`：第一讲，18页教材核心增强版
- `lecture02.html`：导论第二、三节融合课，30页，约75分钟
- `lecture03.html`：导论第四、五节融合课，25页，约72分钟
- `lecture04.html`：第一章“商品”，52页，约125分钟

原先“性质、任务、经济规律与研究方法”的独立第三讲已经完整融入 `lecture02.html`；当前 `lecture03.html` 是新制作的导论第四、第五节课件。

整个目录可直接部署到 Vercel、Netlify、GitHub Pages 或其他静态网页托管平台。课件的 CSS、JavaScript、图形和教学图片均已内嵌，不依赖本机 C 盘、F 盘或任何源资料文件。
